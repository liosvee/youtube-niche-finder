# Sources

Check these again before relying on them; policies change.

- YouTube Help — Understand ad revenue analytics (RPM vs CPM):
  https://support.google.com/youtube/answer/9314357
- YouTube Help — YouTube channel monetization policies (YPP; inauthentic and
  reused content): https://support.google.com/youtube/answer/1311392
- YouTube Data API v3 quota costs (search.list = 100 units; videos.list and
  channels.list = 1): https://developers.google.com/youtube/v3/determine_quota_cost
- Inauthentic content update, 15 July 2025: YouTube renamed "repetitious
  content" to "inauthentic content" and clarified it covers mass-produced or
  repetitive uploads; AI used to improve content remains eligible if it meets
  the other policies.
