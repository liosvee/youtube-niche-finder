# Step 6 — Pilot batch

For the selected niche, plan 3–5 pilot videos from the idea list (different
series). Production happens in the user's production pack (e.g. a
video-editor-agent or shorts agent repo); copy the niche profile across.

After the pilot has run (2–4 weeks of data):
- Record measured costs per video → `economics.costs_usd`, `basis: "pilot"`.
- Record viewing behaviour (CTR, average view duration, returning viewers),
  audience responses and any commercial interest as evidence.
- Re-score criteria 1, 2, 7 and 8, rerun `decide`, and tell the user whether
  the evidence supports continuing, adjusting or switching niche.
