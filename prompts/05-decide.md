# Step 5 — Decide

1. Run `python -m niche_finder decide PROJECT`. Fix anything it reports.
2. Present a short summary: the ranking table, gate failures, the strongest
   candidate and why (demand evidence + reason to choose this channel), the
   close calls, key flags and unknowns. For the leader, show the profile:
   niche type, name, description, language, video types, keywords.
3. Never promise earnings or virality. Say where evidence is thin.
4. **Ask the user to choose.** Do not run `select` until they do. Then
   `python -m niche_finder select PROJECT niche-id --note "..."`.
